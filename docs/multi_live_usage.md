# 多开直播使用说明

本轮修复聊天复制、Enter 快捷弹幕焦点、紧凑顶栏及可复现的资源和并发缺陷，已通过终版独立审查。交付一个新的 Windows x64 便携 ZIP，原有交付物和运行中的程序均保留。

## 进入与操作

1. 正常打开任意直播间，点击工具栏网格图标“多开直播”。切换会等待旧单房间的播放器和发送连接释放，再进入工作区。
2. 点击“添加直播间”，勾选正在直播的关注主播，再点“确认添加”。可刷新关注列表，也可粘贴支持平台的直播间链接。选择器提示剩余名额并识别重复房间；替换时选中一个房间即可。
3. 桌面顶栏默认 **32 逻辑像素**；窄窗口和大字号会自适应显示完整标题与操作。返回、分屏布局、聊天和添加入口均保留，移动端触摸目标不缩小。
4. 顶部声音入口打开“各直播间音量”：逐路显示主播名、0–100% 滑杆、实时百分比和独立静音；“全部静音/恢复所有声音”保留逐路音量。画面页脚、标题栏声音入口或房间菜单的“音量与静音”也可调整。选择聊天目标不改变其他房间的声音。
5. 点击房间标题选择聊天目标。按 Enter 或小键盘 Enter：**无快捷框时打开；框内为空或只有空白时收起；有内容时发送**。输入法确认候选词只提交输入，下一次 Enter 才发送。成功后关闭并清理本次草稿，失败时保留编辑内容。反复开合、点击画面、操作音量/布局/菜单及选择切换后仍可呼出。
6. 快捷框标题和空白区域属于编辑点击区域，点击后保持输入焦点。Tab／Shift+Tab 仍在输入、发送和关闭控件间导航；焦点位于按钮时，Enter 按按钮原有语义操作。按住 Enter、修饰键及其他输入框或菜单不会触发工作区快捷发送。同房间同内容的在途重复提交仍会被共享守卫拦截。
7. 聊天标题的铅笔发送入口已移除，底部输入保持可用。桌面左键或右键点击弹幕，在鼠标位置打开复制菜单；移动端单击弹幕打开带预览的底部卡片。均保留“复制弹幕”和“复制「昵称：内容」”两种选项，空文本不提供复制；打开菜单后新消息到达不会改变已选复制目标，表情富文本保留。
8. 点击顶栏“整窗全屏”或按 F11 进入整窗全屏。Esc 按快捷弹幕框 → 单路临时放大 → 整窗全屏的顺序退出当前层，离开工作区恢复进入前的窗口状态。
9. 桌面支持左右／上下双屏、左一右二、上一下二、四宫格及左一右三。可拖动分割条调整大小，也可拖动标题栏交换画面。画面、聊天、快捷框和音量面板统一显示主播名，直播标题作为补充信息。
10. 桌面最多四路，移动端最多两路。手机竖屏上下、横屏左右排列，旋转保留会话；可逐路替换或关闭，退出工作区等待清理和存档写入。本包仅含 Windows x64 产物。

## 上限与存档

- Windows、macOS、Linux 最多四路；窄桌面窗口不会降低容量或关闭现有房间。
- Android、iOS 最多两路，平板同样按两路处理。默认入口仍为单房间，多开为可选功能。
- 可保存房间标识、布局比例、逐路音量/静音、弹幕开关与聊天目标，并在再次进入时选择恢复。临时放大不替换永久布局。
- 手机读取桌面四路存档时提示容量限制，不自动打开四路；未经明确添加或编辑便退出时不覆盖原档。
- 存档不包含 Cookie、Token、签名或临时播放地址。会话隔离、代际检查、Douyu 发送租约、有界聊天缓冲、表情缓存和日志脱敏均保留。
