# 弹幕输入框布局重设计 v3（最终方案：两套 UI 过渡）

## 核心决策
1. **发送弹幕 = 正式功能**，分阶段：斗鱼 ✅ / B站 ✅ 已可发；虎牙、抖音后续补齐（各自需要抓包逆向）。
2. **过渡期采用两套 UI**：
   - **默认关闭**「发送弹幕」→ 使用**原来的 UI**（无输入框，底部仍是原来的功能按钮行）
   - 用户/开发者在 设置 中**开启**后 → 使用**新布局**（下方三张设计图），输入框直接可用
   - 等虎牙/抖音补齐后，再移除开关、统一为新布局
3. 开启开关的位置：设置 → 其他 → 「发送弹幕」（默认关闭）

## 三形态设计图（开启后）

| 形态 | 图 | 要点 |
| --- | --- | --- |
| 移动端竖屏 | `docs/mockups/1-portrait.png` | 输入框常驻聊天列表下方（一行 56px，仅聊天 tab）；关注按钮移到主播名右侧；刷新/分享收进右上角菜单 |
| 移动端横屏/全屏 | `docs/mockups/2-landscape.png` | 输入框嵌入底部控制条中部；点画面唤出控制条时显示，随控制条收起 |
| 桌面端 | `docs/mockups/3-desktop.png` | 底栏单行：左侧功能按钮（刷新/取消关注/分享/复制链接/复制播放直链），右侧输入框+发送 |

## 输入框状态（同一布局，状态不同）

| 平台/状态 | 表现 |
| --- | --- |
| 斗鱼 / B站 + 已登录 | 正常 |
| 未登录 | 可点，发送时提示「请先登录」并提供入口 |
| 虎牙 / 抖音 | 禁用态：灰显 + 「该平台暂不支持发送弹幕」 |
| 被其他设备顶下线 | 输入框上方出现状态条「弹幕会话已被接管 · 重新登录斗鱼」 |

## 发送前确认（仅斗鱼，会抢会话）

```
发送弹幕会接管账号的弹幕会话
其他设备（浏览器/官方客户端）的弹幕连接会被断开，直到它们点「重试」。
☐ 不再提示（可在 设置 → 其他 中恢复）
                    [取消]      [继续发送]
```
